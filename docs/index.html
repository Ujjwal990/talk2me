Talk2Me

AI-powered chat reply assistant for any web chat platform. Select messages, press a shortcut, get a reply that matches your tone.

How it works

  1. Click into the chat input box on any supported platform
  2. Select the recent messages you want as context
  3. Press Ctrl Shift A
  4. Add optional instructions (text or voice) and click Generate Reply
  5. Click Use It to inject the reply, or Retry for a different take

Works on

WhatsApp Discord Telegram Instagram Google Chat LinkedIn Messengerβ Facebookβ Tinderβ

Privacy Policy

Last updated: May 14, 2026

What data we process

Talk2Me only processes the chat text you explicitly select and only when you press the activation keyboard shortcut (Ctrl+Shift+A). The extension does not:

  • Read messages in the background
  • Log keystrokes
  • Scrape your chat history
  • Track which sites you visit
  • Collect personal identifiers, location, or browsing history

How your data is used

When you trigger the shortcut, the selected text is sent over HTTPS to our backend server, which forwards it to Groq Inc.'s AI inference API for processing. The generated reply is returned to your browser and shown in the floating prompt box.

We do not store conversation content, user identifiers, or any persistent record of your chats on our servers. The selected text is held in memory only for the duration of the API request.

Data sharing

We do not sell, rent, or share your data with third parties for advertising, marketing, or any other purpose. Your selected text is shared only with Groq Inc. for the sole purpose of generating an AI reply, subject to Groq's privacy policy.

Data we never collect

  • Personally identifiable information (name, email, phone)
  • Authentication credentials
  • Financial or payment information
  • Health information
  • Web browsing history
  • Location data

Local storage

The extension stores one preference locally in your browser: the backend server URL. This is stored using Chrome's built-in chrome.storage.local API and never leaves your device. Uninstalling the extension removes this preference.

Your choices

You can stop using Talk2Me at any time by uninstalling the extension via chrome://extensions. The shortcut will no longer work, no data will be processed, and all locally stored preferences are removed.

Changes to this policy

If we change how Talk2Me handles data, we will update this page and bump the "Last updated" date above. Material changes will be reflected in an updated extension release with corresponding release notes.
